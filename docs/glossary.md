# Глоссарий

- **Owner** — единственный владелец помощника и источник явного approval.
- **Approval** — ограниченное по действию, цели и времени подтверждение; не переносится на другие действия.
- **Read-only-first** — режим, где чтение/анализ разрешаются раньше любой мутации.
- **Core** — стабильная channel-agnostic логика ролей, policy и orchestration.
- **Adapter** — перевод внешнего протокола или runtime в внутренний контракт.
- **Facade/Port** — интерфейс к заменяемой реализации без зависимости core от поставщика.
- **OpenClaw runtime** — предполагаемый заменяемый runtime; возможности UNVERIFIED до проверки.
- **Role** — профиль цели, tools, memory, риска и approvals. Всего восемь.
- **Capability** — сквозное умение; multimodal workflow не является ролью.
- **Namespace** — одна из пяти изолированных областей памяти: `tvoe-vremya`, `ai-my-time`, `personal`, `shared-public` или `security-restricted`. Роль и provenance хранятся в metadata записи, а не кодируются в имени namespace.
- **Provenance** — источник, время наблюдения, confidence и цепочка преобразований.
- **Classification** — категория чувствительности данных, управляющая sinks и retention.
- **Sensitive data scan** — детерминированная runtime-проверка перед memory/log/external/audit.
- **Fail closed** — блокировка операции при ошибке или неопределённости контроля.
- **Observed system** — allowlisted система, доступная помощнику только по outbound read-only пути.
- **Reverse trust** — доверие наблюдаемой системы к помощнику для входящего администрирования; запрещено.
- **Subscription OAuth** — доступ в рамках пользовательской подписки, отличный от API billing.
- **Paid fallback** — скрытый переход на тарифицируемого провайдера; по умолчанию запрещён.
- **Quiet hours** — локальный интервал, когда несрочные уведомления откладываются.
- **Draft config** — валидный JSON-пример проектных намерений, не рабочая runtime-конфигурация.
